# CFSTUDIO — DIGITAL MARKETING THAT WORKS

Official repository for **CFStudio**, a Kolkata-based digital marketing brand.

## Brand Assets
Brand logos and graphics are located in `public/brand/`:
- `cfstudio-logo-full.png`: Horizontal logo with wordmark and tagline
- `cf-icon-mark.png`: Iconic geometric CF mark
- `cf-icon-hd.png`: High-resolution CF icon
- `cfstudio-brand-board.png`: Identity guide, dark mode lockup, app icons, and color palette

## Palette & Design Tokens
- Primary Indigo: `#6366F1` (Hover: `#4F46E5`, Deep: `#3730A3`, Soft: `#EEF2FF`)
- Dark Background: `#0B0F1A` (Dark Surface: `#111827`)
- Light Background: `#F8FAFC` (Surface: `#FFFFFF`)
- Borders: `#E2E8F0` (Dark: `#273244`)
- Text: `#0B0F1A` / `#F8FAFC` (Secondary: `#64748B` / `#94A3B8`)
